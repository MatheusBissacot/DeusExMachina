# DeusExMachina
This project aims to explore the societal implications of Artificial Intelligence (AI) through the analysis of a  real-world case study. Our case study will be a closer look inside popular Generative AI models like text-to-image tools such as Stable Diffusion, and the gender and racial bias they perpetuate based on the Bloomberg Article.
